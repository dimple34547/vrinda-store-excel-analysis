# Vrinda Store Sales Analysis 📊

## 📌 Project Overview

This project analyzes Vrinda Store sales data using Microsoft Excel to understand sales performance, customer demographics, order status, and revenue patterns.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- IF, SUM, AVERAGE, COUNTIFS, SUMIFS
- Data Analysis
- Pivot Tables
- Charts & Data Visualization
- Basic Business Insights

## 📊 Analysis Performed

- Sales analysis by category
- Sales analysis by gender
- Age-group analysis
- Order status analysis
- Customer and sales analysis
- Category-wise performance
- Revenue analysis
- Data visualization using charts

## 🎯 Project Objective

The objective of this project is to analyze store sales data and identify useful business insights that can help understand customer behavior, sales performance, and product/category trends.

## 📁 Project File

The complete Excel workbook is available here:

**Vrinda_Store_Sales_Analysis.xlsx**

## 💡 Key Learning

Through this project, I practiced Excel data cleaning, formulas, data analysis, visualization, and presenting business insights in a structured way.
